TEMPORARY NGROK PUBLIC URL FOR THE STREAMLIT APP
================================================

1. Open PowerShell and go to the project folder:

   cd C:\projects\qa-agent

2. Start the Streamlit app:

   .\.venv312\Scripts\python.exe -m streamlit run .\app.py --server.address 0.0.0.0 --server.port 8501

3. Keep that terminal open. Open a second PowerShell terminal.

4. Start ngrok:

   ngrok http 8501

5. Copy the HTTPS URL shown next to "Forwarding". It will look like:

   https://your-temporary-url.ngrok-free.app

6. Paste that URL into TestSprite.

7. Keep both terminals open while testing.

8. When testing is finished:

   - Press Ctrl+C in the ngrok terminal.
   - Press Ctrl+C in the Streamlit terminal.

The ngrok URL is temporary and stops working when ngrok is stopped.

To open this file in Notepad, run:

   notepad .\NGROK_STEPS.txt


TEST THIS APP USING TESTSPRITE MCP IN VS CODE
=============================================

1. Check that Node.js 22 or later is installed:

   node --version

2. Create a TestSprite API key:

   - Open the TestSprite Dashboard.
   - Go to Settings > API Keys.
   - Create and copy an API key.

3. Add TestSprite MCP in VS Code:

   - Press Ctrl+Shift+P.
   - Run "MCP: Add Server".
   - Select "Command (stdio)".
   - Enter:

     npx -y @testsprite/testsprite-mcp@latest

   - Name the server TestSprite.
   - Add this environment variable:

     API_KEY=your-testsprite-api-key

   - Start the TestSprite MCP server from the generated mcp.json file.

4. Start the Streamlit app in PowerShell:

   cd C:\projects\qa-agent
   .\.venv312\Scripts\python.exe -m streamlit run .\app.py --server.address 0.0.0.0 --server.port 8501

5. Open a second PowerShell terminal and start ngrok:

   ngrok http 8501

   Copy the HTTPS forwarding URL shown by ngrok.

6. In VS Code Copilot Chat, send this prompt:

   Can you test this project with TestSprite MCP?

   The application is a Streamlit QA Test Case Generator.
   Use this public URL:
   https://your-ngrok-url.ngrok-free.app

   Test the complete user flow:
   - Open the application
   - Upload a .txt, .docx, .xlsx, or .pdf requirements file
   - Verify pipeline progress
   - Verify generated test case reports
   - Verify Excel and Word downloads
   - Verify Test Strategy generation
   - Verify error handling for unsupported files

7. When TestSprite asks for configuration:

   - Testing type: Frontend
   - Scope: Codebase
   - Application URL: your ngrok HTTPS URL
   - Login credentials: None
   - PRD: upload qa_requirements.txt or README.md

TestSprite should generate reports and test files in a testsprite_tests folder.
Keep both the Streamlit and ngrok terminals running during testing.

When testing is finished, press Ctrl+C in both terminals to stop the app and
the temporary public URL.
